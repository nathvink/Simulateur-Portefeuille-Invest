En clair

    Comment sont construits ces scénarios ?

    1. On tire des blocs d'années réelles

    Chaque scénario enchaîne des blocs de plusieurs années consécutives tirées au hasard dans l'historique 1990-2025 (par exemple 2007-2011, puis 2016-2020…). Tous les actifs de l'année tirée bougent ensemble : on conserve leurs liens (corrélations) et les enchaînements de marché (krach puis rebond).

    2. On applique vos versements

    Chaque mois, votre versement est investi selon vos proportions (avec rééquilibrage : d'abord vers les lignes en retard), en tenant compte des frais annuels des fonds et de l'assurance-vie. Le plafond du PEA est respecté : au-delà, les versements prévus sur le PEA vont sur un compte-titres.

    3. On classe les résultats

    On range les scénarios du pire au meilleur. Le scénario « pessimiste » est celui qui fait mieux que 10 % des cas seulement, le « médian » est au milieu, l'« optimiste » n'est battu que par 10 % des cas.

    Les règles appliquées

    Paramètres modifiables dans l'objet PARAMETRES_FISCAUX en haut du fichier. Taux à vérifier : ils changent avec les lois de finances.

    Simplifications : option pour le barème progressif non simulée ; sur le compte-titres, les dividendes sont en réalité taxés chaque année (ici, tout est taxé à la sortie) ; les impôts dus sur les ventes de rééquilibrage à l’intérieur du compte-titres ne sont pas simulés (dans le PEA et l’assurance-vie, ces arbitrages sont sans impôt) ; pas de droits de succession ni de rente.

    D'où viennent les chiffres ?

    Transparence sur les données intégrées dans ce fichier.

    Important : aucune donnée n'a été téléchargée. Les séries ont été saisies à partir des valeurs historiques publiées par les fournisseurs d'indices, connues de mémoire : elles sont annuelles, arrondies, et peuvent différer de quelques dixièmes de point des chiffres officiels. Les cases ≈ surlignées sont des estimations ou des reconstitutions, moins fiables.
    Tous les rendements sont exprimés en euros, dividendes ou coupons réinvestis. Les séries en dollars sont converties avec le taux EUR/USD de fin d'année (avant 1999 : « euro synthétique » reconstitué à partir du mark allemand, 1 € = 1,95583 DEM). Avec des données annuelles, les chutes brutales à l'intérieur d'une année (mars 2020 par exemple) n'apparaissent pas.

    Séries utilisées

    Rendements annuels en euros (%)

    Après conversion en euros, avant frais. ≈ = valeur approximative.

    Contrôles de calcul

    Le moteur est vérifié au chargement sur des cas simples calculables à la main.

    Ajouter un actif

    Ouvrez ce fichier dans un éditeur de texte, cherchez DONNEES_MARCHE et ajoutez une entrée sur ce modèle :

    MON_ACTIF: {
  nom: 'Nom complet', nomCourt: 'Nom court',
  classe: 'Actions',          // Actions | Obligations | Fonds euros | Immobilier | Or & matières premières
  zones: { 'Europe (hors France)': 100 },
  devise: 'EUR',              // 'EUR' ou 'USD' (converti automatiquement)
  rendements: { 1990: 5.2, 1991: -3.1, /* … */ 2025: 7.0 },   // % par an, dividendes inclus
  // ou bien : niveaux: { 1989: 1000, 1990: 1052, … } (+ dividendes: { 1990: 3.0, … })
  approx: [2025],             // années approximatives (ou 'toutes')
  enveloppes: { PEA: 'non', CTO: 'oui', AV: 'oui' },          // 'oui' | 'etf' | 'attention' | 'non'
  fraisAnnuels: 0.2,          // % par an (frais de l'ETF)
  description: 'Une phrase simple.',
  source: 'Fournisseur, nom exact de l’indice', periode: '1990-2025',
},

    Si un actif n'a pas d'historique complet, les calculs utilisent automatiquement les seules années communes à tous les actifs du portefeuille.

    Simulation à but éducatif, les performances passées ne préjugent pas des performances futures.
